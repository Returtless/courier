# Optimizer parity fixtures

Used to compare **Python** `GeneticRouteOptimizer` (reference) with the future **Kotlin** port.

## Layout

- `*/input.json` — full scenario: `start_location`, `start_time_iso`, `settings`, `orders`, `nodes`, `route_matrix`, optional `rng_seed`.
- `*/expected.json` — generated by `tools/export_optimizer_golden.py` (do not hand-edit without re-export).

### Android golden test

- `tiny_two_orders`: `TinyTwoOrdersGoldenParityTest` — [ParityRouteFacade] + **GA** (как Python без OR-Tools), **SplitMix64** по `rng_seed`; см. `export_optimizer_golden.py` и `src/services/genetic_rng.py`.
- `telegram_spb_route_head5`: 5 остановок; матрица в JSON (haversine при генерации, [generate_telegram_spb_fixtures.py](../tools/parity/generate_telegram_spb_fixtures.py)). После смены GA перегенерируйте `expected.json`.
- `telegram_spb_all19`: все 19 заказов (`input.json`); GA на Kotlin/Python без полного перебора.

### Cluster phase (intermediate)

- Regenerate `intermediate/cluster_orders.json`:
  `python tools/parity/export_cluster_intermediate.py --fixture parity_fixtures/tiny_two_orders`
- Copy/sync to `android/app/src/test/resources/parity_fixtures/tiny_two_orders/intermediate/cluster_orders.json` when it changes.
- JVM test `ClusterParityTest` compares Kotlin [ClusterSynchronizer](android/app/src/main/java/com/courierplanning/routeopt/cluster/ClusterSynchronizer.kt) to that file.

## `nodes` and `route_matrix`

- `nodes[0]` must match `start_location` (same lat/lon after rounding to 5 decimals).
- `nodes[i]` for `i >= 1` must match `orders[i-1].lat` / `lon`.
- `route_matrix` uses string keys `"i,j"` (comma) for directed edge **i → j** with `distance_km` and `travel_min`.

## Regenerate goldens

From repository root:

```bash
PYTHONPATH=. python tools/export_optimizer_golden.py --fixture parity_fixtures/tiny_two_orders
PYTHONPATH=. python tools/export_optimizer_golden.py --fixture parity_fixtures/telegram_spb_route_head5
```

Экспорт подменяет `random` на **SplitMix64** с тем же seed, что и Kotlin JVM — иначе golden не совпадёт с `SplitMix64Rng(rng_seed)`.

## Math vectors (Kotlin vs Python)

- `math_vectors/haversine.json` — distances from `tools/parity/export_math_vectors.py` (same formula as `GeneticRouteOptimizer._haversine_distance`).
- Regenerate: `python tools/parity/export_math_vectors.py`
- Copy/sync to `android/app/src/test/resources/parity_fixtures/math_vectors/haversine.json` when values change.

- `math_vectors/time_windows.json` — parsing + minute range from `src.models.route_types.Order` via `tools/parity/export_time_window_vectors.py`.
- Regenerate: `python tools/parity/export_time_window_vectors.py`
- Sync copy to `android/app/src/test/resources/parity_fixtures/math_vectors/time_windows.json` when cases change.
